# Assignment 5 - JavaScript Basics (DOM Manipulation & Events)

## Description
This project is part of the "Web technologies Front-End Development" course (Assignment #5). It focuses on the fundamentals of JavaScript, including working with the Document Object Model (DOM), handling events, and creating dynamic web pages.

## Project Structure
The project is divided into 4 parts, accessible via a navigation bar:
* **Part 1 (Introduction):** Basic JS concepts, variables, operators, and console output.
* **Part 2 (DOM Manipulation):** Changing text content, styling elements, and dynamically adding/removing list items.
* **Part 3 (Events):** Mouse events (hover effects), keyboard events (real-time input display), and a basic functional calculator.
* **Part 4 (Interactive To-Do List):** A mini-project where users can add tasks, mark them as completed, and delete them.

## Technologies Used
* HTML5
* CSS3
* JavaScript (Vanilla)
